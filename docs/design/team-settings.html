Owner cuối cùng không thể bị hạ quyền

Nhóm luôn phải còn ít nhất một owner. API trả 409 last_owner khi bạn đổi role của owner cuối cùng hoặc tự gỡ mình khỏi nhóm — hãy chuyển role owner cho người khác trước. Đây là ghi chú chỉ đọc, không phải một thiết lập.

API token và JWT dùng chung một Bearer middleware

Mọi request tới /api/v1 đi qua RequireAuth: header Authorization: Bearer <token> được verify như JWT trước, nếu không phải JWT thì tra hash token. Scope map sang role khi kiểm tra RBAC — read → read-only, deploy → admin, admin → owner — nên token luôn bị giới hạn trong nhóm đã tạo nó.
