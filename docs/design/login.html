Gotham

Self-hosted PaaS

Control plane cho hạ tầng của chính bạn

Một binary Go chạy control plane, một agent nhỏ trên mỗi node. Không dịch vụ ngoài, không tầng nào bạn không đọc được source.

  • Self-hosted trên VPS ≥ 1 GB RAM

    Control plane là một binary Go cùng PostgreSQL và Redis; 1 vCPU / 1 GB là đủ để bắt đầu.

  • Đường điều khiển qua gRPC mTLS tới agent

    Agent gọi Docker Engine trên node; CP ↔ agent dùng protobuf có version qua :9442, chứng chỉ do CA nội bộ cấp.

  • Cập nhật ký Ed25519, có rollback

    CP và agent tự cập nhật từ GitHub Releases, xác minh chữ ký trước khi thay binary và giữ bản cũ để quay lại.

  • 4 build engine + template 1-click

    Dockerfile, Railpack, Buildpacks và static; thư viện template dựng WordPress, Nextcloud, n8n hay Uptime Kuma trong một cú nhấp.
