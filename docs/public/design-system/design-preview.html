Gotham design system

Dark console token catalogue

A catalogue of the tokens the Gotham web console actually ships. It is a documentation specimen, not a second component library: the runtime theme is Naive UI with the overrides in web/src/app/App.vue, and web/src/shared/styles/tokens.css is the source of truth.

  • 144 effective tokens
  • generated from tokens.css
  • dark console only
  • works offline

Reading this offline? The console ships Google Sans and JetBrains Mono, but this page deliberately loads no font files and no network assets. Text falls back to Helvetica/Arial and the local monospace font, so spacing and wrapping may differ slightly from the console. Gotham has no light theme switch: the light terminal palette is a separate terminal feature, not an app theme.
